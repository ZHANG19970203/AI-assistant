# 学生中心学习伴侣：功能与教学验收清单

更新日期：2026-10-28。按用户新增的“学、练、记、伴与六维反馈”诉求组织。这里的“当前”指本地基础工程，不能解释为微信上线、正式课程教师批准或真实学生试点完成。已完成新增网页与后台的独立源码审查；实际浏览器操作、自动化测试和小程序验证范围以项目验证报告为准。下列复选框是验收项，不表示所有项目均已执行通过。

## 一、产品与教学边界

学生的主要路径是选择学习目标、查阅材料、独立尝试、获得适量帮助、核对证据、用自己的话再解释。教师维护资料、评价证据和处理困难。不能把教师后台当学生端的主要体验，也不能以聊天次数、停留时长或连续签到替代学习目标。

陪伴式引导是可退出的支持。学生可以关闭提醒，按需要选择提示、解释和教师帮助；不要用“离开会落后”“只有我理解你”等话术诱导依赖。提供解释是教学责任的一部分，“先给提示”不能变成永远不给解释。

## 三、学习闭环的可执行验收

- [ ] **先尝试**：学生可选择选项或写下初步解释；不确定时允许明确表达“暂不确定”。不能用空白作答推断态度或能力，也不要求先完成无关打卡。
- [ ] **逐级提示**：一级提示指向观察要素或概念；二级提示给比较方法；查看了提示不产生羞辱性标签，不扣减未经说明的能力分。
- [ ] **证据核对**：一次尝试后可主动查看完整解释和出处。正确作答的解释同样有来源；标题、章节/页码、版本和摘录可辨认。解释不得冒充用户教材原文。
- [ ] **自己再解释**：查看证据后，有可选的修正/笔记入口，能记录“原判断—证据—修正—还不确定什么”。不能仅凭答对或看完解释宣布已掌握。
- [ ] **迁移**：提供一个可选择的新动作或情境，重用分析步骤；换题只是练习机会，不自动认定迁移能力。
- [ ] **学生选择**：学生可暂停、退出或请教师解释；常规资料阅读与来源核对不应因未作答永久锁定。

当前选择题自动检查的是选项是否符合演示答案，不能从中自动判断文字推理、真实动作操作或临床技能。学生作答思路即使已保存，也不得显示为已被AI或教师评过。

## 四、何时转教师

- 知识库没有足够的已审核证据，或者引用内容与问题不对应。
- 资料版本冲突、原文可能有误、图像结构或实际实验观察无法核实。
- 学生经过提示仍不能解释关键依据，或主动提出需要教师讲解。不要机械重复同一提示。
- 问题涉及真实患者诊断、个体康复处方、操作风险或超出课程资料范围。
- 人工六维反馈需要形成正式教学评价，或学生对评价及所用证据提出异议。

本地“待教师处理”队列只表示记录在本机。没有实现教师通知、回复或关闭流程时，不得显示“老师已收到”“已转人工处理完成”。

## 五、六维反馈的含义与验收

六维名称为**概念辨析、动作观察、证据运用、情境迁移、反思修正、自主规划**。它们用于讨论具体学习作品，不能作为未经验证的综合能力诊断或心理画像。

| 维度 | 可讨论的证据例子 | 不足以单独证明的内容 |
|---|---|---|
| 概念辨析 | 对概念的比较说明、选择题后的理由 | 一次选对、背出术语 |
| 动作观察 | 身体节段、姿势、方向及观察条件的记录 | 打开动画、停留时长 |
| 证据运用 | 判断与具体资料片段及版本的对应说明 | 点击过资料、罗列标题 |
| 情境迁移 | 新动作中的步骤运用及适用条件 | 重做同一道题、复制旧结论 |
| 反思修正 | 原判断与修正、修正原因及验证 | 笔记字数、连续签到 |
| 自主规划 | 可执行目标、步骤与根据结果调整 | 单次任务完成、提醒开启 |

- [ ] 六维初始全部为 `null`，界面显示“待证据/待评价”；不能用0填充缺失维度或将其连接成低能力多边形。
- [ ] 教师每次反馈都绑定该学生已经存在的学习证据，显示评价日期、证据范围、评分依据与可行动建议。
- [ ] 0–4表示**教师对该份证据中目标表现的反馈**；0不能表示“没有交作业”或“该学生没有能力”。没有足够证据时应保留空值，先补证据。
- [ ] 练习正确/错误、答题次数、笔记数量、任务进度和信心自评分开展示；不自动折算六维分值。
- [ ] 仅当六维均有人工反馈时绘制完整反馈多边形；部分维度有评分时显示对应点和文字，未评维度保持空缺。
- [ ] 图旁明确最近一次或本次评价、证据数量与日期。单份作品的反馈不能被解读为课程总能力；稀疏证据不输出排名、风险诊断或精确掌握百分比。
- [ ] 学生可查看依据并提出疑问；正式版本须提供教师复核入口。当前若只保存反馈，应如实称为记录，不能声称闭环已完成。

## 六、学、练、记、伴的数据与界面

- [ ] 学生入口直接呈现自己的学习任务、练习、笔记和下一步，不要求操作教师配置。
- [ ] 提交练习、笔记、反思与困难描述后刷新页面仍可看到；重复提交的行为与对同题多次练习不被混作同一指标。
- [ ] 事件表显示实际事件内容；任务卡能回看反思、信心自评与提交时间。
- [ ] 下一步建议注明来自哪些学习记录，允许忽略或另选任务；不因鼠标点击、浏览停留或未开启提醒认定学习困难。
- [ ] 自述困难保留“学生自述”含义；规则建议不写成AI已理解其情绪、意图或能力。
- [ ] 关闭提醒后停止后续模拟/发送；免打扰时段遵从学生设置。关闭提醒不影响课程资料和基本学习功能。
- [ ] 本地演示身份与正式登录清晰区分；仅用虚构信息演练，学生数据库及API密钥不进入交付压缩包。

## 八、本次独立源码复核结果

复核文件为 `web/app.js`、`web/companion.js`、`lib/service.mjs`、`lib/companion.mjs`、练习种子与小程序连接配置。未以源码审查代替微信平台或真实学生验收。

- 已有首页自述困难提交、规则建议和学生自主选择入口；建议来自有限分类规则，不是大模型理解情绪。
- 错误作答返回方向提示；提交过一次后可以查看三级证据与完整解释。正确作答也返回带标题、章节、版本和摘录的引用。
- 可把练习思路带入笔记提纲，再由学生自己写修正；笔记与任务反思保存在本地数据库。
- 练习作答、笔记、反思和困难记录均不会自动产生六维分值。六维由演示教师选择已有作品、量规分值与评价说明后提交；服务端验证该证据确实存在且属于演示学生。
- 学生可查看各维最近一次教师反馈、评价标准与证据编号。不同维度可能来自不同日期或作品，不能把图形解释为同一测次的标准化成绩。
- 资料待审核过滤、教师试卷/研究材料隔离以及本地演示身份边界仍由服务端保留。实际公网权限、教师通知与答疑闭环尚未完成。

## 九、正式试点前的最低验证

1. 教师审定首章资料与形成性练习，并抽查引用、答案和提示是否促进解释。
2. 用可答、不可答、跨课程、未审核资料、泄题请求测试检索与拒答。
3. 用空白六维、单一维度、稀疏证据和完整反馈分别检查图形与文案；确认缺失不变成零分。
4. 演练“先尝试—提示—证据—再解释”和“学生主动请教师讲解”，确认没有重复提示死循环。
5. 验证真实身份与课程权限、手机网络访问、学生订阅/撤回、免打扰、去重、失败回执和备份恢复。
6. 通过少量学生自愿试用，观察能否独立解释、核对来源与选择下一步，再决定是否扩大范围。此处是拟开展的验证，不是本次已经完成的研究。
