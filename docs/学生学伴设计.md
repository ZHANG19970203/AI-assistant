# 《人体运动学》学生学伴设计

版本：2026-10-28。以下是教学与产品设计，不把政策文章、营销叙述或未经核查研究作为效果证据。当前是本地原型，尚无真实课程大模型答疑、自动能力诊断、视频处理或微信推送。

## 学生主流程

学生进入后先看到本节课的目标和下一件小事。主流程为：查看任务→自己先试→需要时取线索→重试或带问题问教师→用自己的话记一句→选择下一步。系统优先问“你已经怎样想？”而不是立即给最终答案。一次只给少量帮助，学生可跳过 AI、独立完成、暂停或关闭提醒。

“卡点”优先由学生自己表达，例如“术语分不清”“看不清动作”“找不到依据”“不知道怎样修正”，不能根据停留时间、点击频率或沉默自动断定理解水平、情绪或学习意愿。教师在课堂上可以暂停答疑、开放一个观察任务或结束讨论；AI 不应在教师讲授时持续打断。

建议提示阶梯：

1. **厘清问题**：学生说清观察对象、自己的判断和最不确定的一点；不要求长篇输入。
2. **一级线索**：给观察方向、概念对照或检查问题，不给选项答案和完整解题过程。
3. **二级依据**：指向教师审核资料中的具体页/节，展示短摘录，让学生自己连接证据。
4. **再次尝试**：要求学生修订一句话或重新选择，并说明改变的理由。
5. **教师接手**：资料不足、冲突、反复尝试仍不清楚或涉及实际操作安全时，整理“问题—已试方法—资料位置”交教师。没有教师反馈时保留待解决状态，不伪造回复。

正式考试和教师受限题库不进入学生答疑索引。分级提示不用于绕过考试隔离；形成性练习必须经过教师明确开放。

## 六个具体课堂场景

| 场景 | 学生可做的事 | 学伴怎样帮助 | 教师控制与证据 |
| --- | --- | --- | --- |
| 1. 课前提问 | 阅读指定章节；用一句话预测动作分析时先看什么，写下自己的疑问 | 问“你已知道什么、还缺什么”，提供资料位置和一个检查问题；不代写预习作业 | 教师选择首章和资料，查看共性困惑；保留学生原始预测及后续修订 |
| 2. 课中运动观察 | 在教师安排下观察一个抬臂/坐站等动作，描述起止位置、观察方向与可见变化；不强迫上传身体影像 | 提供“观察到的现象/我的解释/仍不确定”的记录框；学生主动求助才展开线索 | 教师决定观察任务与节奏，实际动作操作依课堂要求；记录描述作品，不把打开页面算完成 |
| 3. 案例多角色讨论 | 小组分别从观察者、证据核对者、解释者、质疑者视角讨论同一教学案例，写出共识和分歧 | 展示角色问题卡、提醒区分观察与推论；未来可在审核案例范围内生成追问 | 当前没有 LLM，不假装已模拟多角色对话。学生/同伴的真实发言由其记录；教师收束争议 |
| 4. 分层练习 | 先做概念辨析，再做动作描述，最后尝试改变情境后的解释；可以主动选基础层 | 首次作答后给“检查哪一步”的线索，逐级提供来源；不直接输出正确选项与完整答案 | 教师审核题干、正确判据、难度和提示；练习作答结果独立统计，不能自动变成六维能力评分 |
| 5. 错题反思 | 写“我原来怎样想—哪里需要修正—依据是什么—下次如何检查”，再次尝试 | 给反思框架，帮助回到对应资料；需要时转交教师，避免只复制解析 | 教师查看修订前后作品与理由；学生能把仍有疑问标记为待讨论，而非被迫勾选已掌握 |
| 6. 课后下一步 | 关闭提示独立复述；从“补一条证据、换一个情境、向教师提问、按计划休息”中选一步 | 根据学生明确选择和教师已评证据给一项建议；允许学生修改计划或不接受 | 教师设下一课任务和截止时间；提醒自愿、可关闭、遵守安静时段，不以连续使用或聊天时长评价学生 |

上述动作和案例是可选教学场景，不构成针对个人的医学判断或治疗指导；正式内容以教师选定且审核的课程版本为准。

## 六角形学情反馈：显示证据，不造分数

六个维度采用同一尺度，但评分必须对应可查看的作品和公开量规。界面显示“本章节、量规版本、证据时间范围”，不同章节/标准不能直接合成一个终身能力分。

| 维度 | 可作为评分依据的作品示例 | 不足时的下一步建议 |
| --- | --- | --- |
| 概念辨析 | 学生用自己的话区分两个课程概念，并给合适反例 | 用一句话说明两者差别，再请教师核对 |
| 动作观察 | 具体动作的起止位置、观察方向与可见现象记录 | 补写观察条件，把现象与解释分开 |
| 证据运用 | 指向已审核资料位置，说明该段怎样支持判断 | 为一条结论补充来源及关联理由 |
| 情境迁移 | 换一个动作或约束条件后作出的解释与依据 | 在教师允许的另一个情境中再次解释 |
| 反思修正 | 保留第一次尝试、修改后的解释及修改原因 | 写清“我改变了什么、为什么改变” |
| 自主规划 | 学生选择的可执行下一步及之后回看计划的记录 | 自选一件可在约定时间完成的小事 |

建议量规为教师可修订的 0–4 级：0=教师已有证据显示该任务尚未达到最小要求；1=在明确提示下部分完成；2=在少量提示下完成关键步骤；3=可独立解释并使用依据；4=可在新情境解释并检查局限。量规适用性与措辞须课程负责人确认，当前未作为已验证测量工具使用。

`null`=没有足够证据或尚未教师评阅，与 0 分严格区分。缺一维就保留空缺，六维均缺时显示完整底图与“待证据”，不画填充成绩面、不把缺失值补成 0，也不凭自评、练习正确率或使用行为生成分数。候选证据可来自学生笔记、任务反思和练习作品；这些记录本身不等于教师评分。

每条正式评分至少保存：学生、课程/章节、维度、量规版本、分值、证据 ID、教师 ID、评分时间、简短理由。学生可点开证据和提出更正；教师修订评分保留历史。AI 可辅助整理待评证据，但不能自称已完成能力诊断。

练习区单独显示作答次数、题目范围、独立作答还是使用过提示，以及本次结果；如显示正确率，标明分母和演示/正式内容来源。小样本和提示后的正确率不能被包装为综合掌握度。

## 功能分期与当前完成边界

| 阶段 | 能力 | 限制 |
| --- | --- | --- |
| 当前小程序离线骨架 | 课前中后任务、原创演示练习、逐级提示、学生笔记与反思、六维待证据底图 | 进程内状态，重启重置，与网页数据库独立；无微信身份、真实课程、教师评分或模型 |
| 当前网页/后端原型 | 以实际交付界面及测试报告为准 | 不把接口存在视为正式课程、微信或模型已接入 |
| 单章试点 | 教师审核内容与形成性练习、真实身份与权限、证据引用、教师评分、卡点升级、学习任务提醒 | 先做准确性、隐私与授权验收，再招募自愿试点学生 |
| 第二阶段候选 | 自动视频转写/画面理解、语义摘要、语音识别与朗读、含答案的自动出题、受控角色追问 | 当前未实现；已有PPTX/字幕文字提取、分段收音基础与抽取式结构/开放题草稿，见《课件与课堂即时整理》；真实模型内容仍待教师审核 |
| 后续 | 多章次的纵向证据、复习建议、实验室事件接入 | 需要真实教学效果和数据质量验证，不根据在线时长宣称“实时了解学生” |

不设置引导不健康依赖的情感承诺、内疚提醒、强制连续签到和退出惩罚。学伴是否有价值，取决于学生能否逐步减少提示、独立解释、发现并修正错误，以及教师负担是否下降。
