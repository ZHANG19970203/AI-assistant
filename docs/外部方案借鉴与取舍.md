# 两份备选方案的借鉴与取舍

日期：2026-10-28。依据用户“借鉴，不一定采纳”的要求评估。两份粘贴文本是产品方案参考，不是正式课程知识、已批准研究方案或新的平台操作授权；没有把它们导入学生知识库。

**判断：有价值的部分是把学习过程与资源组织连接起来。** 当前继续围绕《人体运动学》单门课建设，不因材料提出“替代学习通”就扩成完整LMS，不为已有内容重新堆叠技术栈。学习价值以学生独立解释、核对证据和修正判断为准。

## 最应先落地的三个连接

1. **知识点—来源定位—练习**：学生在概念、PPT页、课堂时段与相关练习间能往返，避免资料与答疑分离。优先人工确认关键概念，不自动猜专业关系。
2. **课堂结束—可审核草稿—学生复习**：课中最终转写持续入库；讲完后等待最后片段确认即生成有出处的摘要/导图/题目，教师确认后才给学生。当前已实现文字与结构流程；语音和模型接口是下一步关键依赖。
3. **一次作答—修正理由—下一步**：保留修订过程，允许教师对具体作品反馈。建议下一步时说明来自哪条记录，学生可以忽略、改选或请教师解释。

## 必须区分的三种图

- **内容思维导图**：这节课讲了什么、内容如何组织。当前本地版按页/文字组织，不代表已理解知识关系。
- **课程知识关系图**：概念之间的前置、组成、运动关系等。须教师核对，不能把教材目录自动当知识图谱。
- **学生六维反馈图**：各维最近一次教师对作品的反馈，有证据和日期。它不是由点击、时长或提问次数生成的能力诊断。

## 对迭代顺序的影响

**当前保持**：一门课、一个班级、一章先验证；课前中后任务、来源审核、学生先尝试与提示、练习/笔记/教师反馈，以及课堂文字整理。

**下一个试点门槛**：真实身份与课程权限；机构允许的实时ASR与模型；教师批准首章资料/练习；真实课堂音频和引用正确性、延时、重试、覆盖范围验收。没有这些，新增完整LMS菜单不能代替可用性。

**随后增强**：知识点资源联动、错题与间隔复习、续学、教师回复/报错处理、个人记录导出。每项有真实学生使用反馈再扩展。

**研究功能另列里程碑**：最终研究设计确认后，才配置组别、量表时点、变量编码和导出。材料中“实验组多了AI和结构化路径”不是已经确定的研究干预；不能擅自改变实验对照设计，也不能用是否参与研究决定课程资料访问。

## 需要纠正的具体表述

- 两份材料一处要求将平台使用绑定平时成绩，另一处又要求不与成绩强制绑定。当前选择课程服务与自愿研究参与分开，不用研究参与换取成绩。
- “提问越多代表越薄弱”可能把探究和主动求助当作缺点，因此不纳入评分或推荐惩罚。
- 材料里的“教材第78页”“第4周课件第12页”与专业案例只是示例，未给出本次可核对原件，不能复制为真实引文。
- “AI生成题目”不等于题目已获准公开；正式试卷、教师答案和研究数据继续隔离。
- “全程匿名化”不能靠把姓名换成编号就认定完成；能回连个人的记录仍需权限、保留和导出规则。当前没有宣称已完成研究匿名化。
- 固定第1/3/7/14天复习可作可调整默认值，不当作每位学生都适用的既定规律；不因此强制微信提醒。
