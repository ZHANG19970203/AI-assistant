# 学习闭环与课程资料管理

## 让系统逐步改进

当前 MVP 使用“教师审核的知识更新”逐步提高答疑质量，而不是拿学生原始对话自动训练模型：

1. 学生带着自己的初步解释提问。答疑记录、检索出处和模型/本地模式保存在本机数据库；配置 DeepSeek 时，当前问题、初步解释和检索摘录会发送给 SiliconFlow 生成学习提示。
2. 学生可标记“有帮助”或“需要教师核对”。资料检索不到依据的问题也会进入教师队列。
3. 教师查看原问题、学生初步解释、系统答复、引用和反馈，决定是补资料、修正解释，还是调整任务设计。
4. 教师写下修订，系统先将它存为待审核课程资料。教师再次审核后，它才进入学生问答检索。
5. 后续可按章节统计重复问题、未解决问题、低反馈答复与任务反思，帮助教师定位要补讲的概念。

学生反馈是改进线索，不会自动当作标准答案；模型参数也不会因为聊天次数增加而自行更新。如此能让“越用越适合这门课”建立在教师把关、可追溯的课程资料上。后续如要微调模型，应另设经学校批准、告知学生、去标识化且教师审查的数据流程。

## 教师如何放资料

在教师端打开“课程资料”：

1. 先创建章节，填写顺序、简介和学生开放时间；章节可立即发布、定时开放或暂存为草稿。
2. 选择章节后上传单个文件，填写名称、版本、可见范围和开放时间。
3. 上传后核对原文件及文字提取结果，再点“审核并开放”。保密试卷或研究资料可设为仅教师。
4. 学生端“课程章节”按章节显示资料。视频/音频可在页面播放；PDF、Word、PPT 等可打开原件。

支持 TXT、Markdown、SRT/VTT、DOCX、PPTX、PDF、MP4/WebM/MOV/M4V 与 MP3/M4A/WAV/OGG，单文件上限 128 MB。TXT、Markdown、字幕、DOCX 与 PPTX 会提取文字；提取的课程文字经教师审核后才进入 RAG。PDF 当前保存并供阅读，但不自动提取正文，扫描件需要 OCR 或补录文字。视频和音频只保存、播放，不自动转写；上传对应的 SRT/VTT 字幕后，字幕可参与课程问答。

文件目前保存在本机项目的 `data/runtime/course-resources/`；正式部署前应迁移到有访问控制的对象存储，并配置备份、容量和留存策略。

## 章节任务与定时

教师端“任务与推送”可设置：

- 课前、课中或课后阶段；
- 所属章节；
- 学生显示时间；
- 完成截止时间；
- 学习目标和反思要求。

没有填写显示时间的任务创建后立即可见。未来任务到达显示时间后，学生刷新学习页面即可看到。教师的本地模拟提醒记录不是微信消息；小程序登录、订阅授权、消息模板和真实定时推送仍未接入。

## 当前边界

- 当前为本地网页原型，教师/学生身份切换只是演示，不是生产身份隔离；不能直接用于真实班级数据。
- 上传只支持单文件逐个提交。目录拖拽、批量导入、云端权限、断点续传和版本回滚待后续建设。
- 未接 OCR、视频/音频 ASR、自动字幕、向量检索和模型微调。
- 教师是知识发布者；系统记录问题与反馈，用于教师判断和更新课程资料，不能替教师判断学生能力。
