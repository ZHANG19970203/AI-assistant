# 人体运动学AI助教 v0.7

本仓库提供源码，不包含密钥、学生数据及正式课程文件。GitHub Pages 不能直接运行本项目的 Node.js、数据库、邮件和AI后台；当前版本按下方说明在本机启动。

本版围绕一次学习组织内容：教师编排 → 按阶段发放 → 学生专属入口 → 学习记录回传。学生不看课程目录，资料、单选练习、AI 答疑都属于本次学习的课前、课中或课后阶段。

## 启动

需要 Node.js 24 或更新版本，首次运行必须在项目目录安装依赖：

    npm install
    npm start

Windows 安装依赖后也可双击 start.cmd。教师入口：http://127.0.0.1:4317/#teacher-mail 。服务停止后，邮件检查和数据接收也停止。
将 .env.example 复制成 .env.local，在本机填写自己的模型、QQ邮箱配置。源码包不含密钥、授权码、实际名单、上传文件或数据库。无模型配置仍可预览和检索已审核摘录。

## 教师使用顺序

1. 章节：左侧目录树选择课节，右侧查看、上传和审核资料。支持折叠目录、新增同级/子目录、编辑名称及设置上级/开放时间；目录数字显示实际资料数量。目录树按教师截图分为“人体运动学虚拟实验室”和“人体运动学概述”，保留9个可辨认课节，未凭空填入课程文件。
点击章节工具栏“练习与讨论”可携带当前课节进入学习引擎。章节改名和调整上级不更换原有资料与学习任务的关联；父目录未发布或未到开放时间时，其下资料不会进入学生检索。

2. 学习引擎：页面标题为“请下放学习任务”。可直接新增章节、修改章节名称，选中章节即显示已放入的资料，点击“查看资料”在线预览；修改章节名称保留原有资料与学习记录。课前、课中、课后通过同一页的三个按钮切换，每次只展示一个阶段，切换保留输入，保存时同时保存三个阶段。各阶段分别提供视频、文档、音频、讨论、单选练习、体感/口头题以及独立思维导图素材框。单选题的题干、A—D选项、正确选项及解析逐项分行。文件可拖入或点选导入，审核后勾选使用；本章已有资料可重复选用。
3. 各阶段可编排最多20道单选题；点击“保存并下一道”立即保存当前题目，已保存题目可修改、删除，刷新后保留，已发任务保留原题。原有最近一次学习安排的题目会在升级时一次性导入章节题目列表。还可填写思考题、体感动作、口头题并要求提交思维导图。教师可上传任务导图图片，学生可提交PNG/JPG/WebP图片（单张5 MB以内），也可手绘。由教师核对题目与课程依据。未配置阶段不发放。
4. 分别设置阶段开放时间，空时间表示发放后立即开放，有时间则到时开放和发送该阶段邮件。不再手填截止时间；每位学生每阶段从首次开放起固定开放7天。
5. 保存学习安排，再选一个邮箱私发或导入Excel名单群发。第一行使用“姓名”“邮箱”，支持.xlsx，最大5 MB，重复地址合并，错误地址提示。名单支持新增、删除、全选、取消全选，保存勾选状态，已成功发送的地址显示“✓ 已发过”。删除名单不删除历史学习记录。
6. “本机预览学生端”不发送邮件，预览记录单独标记。正式发放前须配置可用公网网址并确认收件同意。
7. 页面下方每5秒更新全班人数、发放人次、累计学习进入次数、AI使用次数、各模块和六维完成数。预览记录不计入全班；同一邮箱跨学习安排汇总，同一次任务重复作答不增加完成数。可展开查看按次活动和答疑，审批补学申请或重置补学次数。

学生在“学情反馈”填写阶段反馈，教师在“学习过程反馈 → 学生反馈”查看、搜索和回复；双方页面打开时每5秒自动更新，回复输入不会被自动刷新清空。反馈独立保存，不影响六维完成率。课前蓝色、课中橙色、课后紫色分区。

保存产生独立版本，已发学习安排不会随新版本改变。专属链接用于记录归属，请勿转发；不是实名登录。SMTP已接受不代表进入收件箱或已读。

## 学生体验与记录

邮件展示本次标题、阶段要求和“进入本次学习”链接。邮件客户端不能运行完整网页交互，播放器、AI答疑和实时记录在链接打开的学生页中使用。
学生只看到本次学习。未到时间的阶段不返回内容或答案。资料打开记事件；视频/音频在前台实际播放时按约10秒回传播放秒数，跳转播放进度不算观看。单选题在服务端判分，提交后返回解析。
AI只检索当前阶段分配且已审核开放的资料，资料不足则说明不足。这些是浏览器上报的行为记录，不是防作弊证据，也不证明理解掌握。断网或直接关闭浏览器可能丢失末尾片段。不会监控学习页以外的行为。

## 上传平台前

此包是本机可运行的应用源码包，不是纯静态网站。Node后端、SQLite持久存储、上传目录及定时进程必须持续运行。只上传HTML/JS到静态托管平台无法提供完整功能。
当前服务器只接受本机地址，教师管理仍是本机演示身份。不要直接公开本机端口。拿到平台和网址后，需要配置HTTPS、反向代理、教师登录与权限、学生入口访问、持久数据盘、后台进程，再设置 PUBLIC_BASE_URL=https://你的域名 。填写变量不会自动完成部署或解除本机限制。
没有公网地址时，正式发放专属链接邮件会被阻止，避免学生收到打不开的localhost链接。原邮件代码和历史记录保留；旧的普通文本任务邮件不属于本版主流程。

## 文件与备份

- web/flow.js：教师编排、发放、过程反馈。
- web/study.html、web/study.js：专属学生学习页。
- lib/lesson-flow.mjs：阶段权限、分配、记录、判题、范围内检索和阶段邮件。
- data/companion.sqlite：运行后生成，含学习安排、专属链接及学习记录，不可公开上传。
- data/runtime/：实际上传的课程文件，需持久保存和备份。
- .env.local：私人配置，不进入版本库或源码包。

DOCX/PPTX/TXT/Markdown/SRT/VTT可提取文字；PDF和音视频可保存展示，但PDF正文/OCR及音视频自动转写未实现；视频答疑需配字幕等文字资料。旧课堂工作台、微信源码仅为历史工程，不在本版主界面使用。

## 录音与课堂整理

教师在课中勾选“AI伴学 · 课堂录音与分析”后，学生可启动课堂录音；布置口头题时可选择口头作答录音。先确认授课教师/相关人员同意及音频转写用途，然后由浏览器申请麦克风。使用独立约60秒音频片段上传，保存、转写并在结束后汇总摘要、知识点和知识结构。仅支持具有 MediaRecorder 的现代浏览器；公网麦克风需要 HTTPS。上传有少量切片间隙，后台/休眠可能影响采集，真实长课时与手机机型尚未验收。

语音转写使用硅基流动 FunAudioLLM/SenseVoiceSmall，可用 SILICONFLOW_ASR_MODEL 改配置；整理使用现有 DeepSeek。官方接口：https://docs.siliconflow.cn/docs/api/audio-transcriptions-post 。已用合成中文语音真实验证转写与摘要，出现“节段”被识别成“阶段”的误差，结果保留为整理草稿；必须核对，不作为权威讲义。转写失败仍保存录音，支持重试。未打开用户的真实麦克风，也未验证真实课堂录音。

## 学情与界面

学生有知新学习、学情反馈、温故学习、亡羊补牢学习四个入口。学情反馈只显示完成情况和六维评价；不显示课程目录或宣传口号。

六维固定为课前讨论、课中讨论、课后讨论、课前视频、课前体感、课后导图。每维显示“已完成次数 / 已布置次数 × 100%”，不是能力评分。以“学生 + 学习安排 + 阶段 + 任务”为一次；只统计已开放任务，同一任务重复提交不会增加分子。没有布置时显示“未布置”。讨论以提交作答为完成，体感为学生点击完成，导图为提交图稿；视频以播放器上报的去重有效播放区间覆盖时长达到90%为完成。该覆盖率依赖浏览器数据，不能证明理解或防作弊；旧版本仅有秒数的记录不自动推断为完整观看。

温故学习按每次学习安排及阶段提供入口，单独记录复习进入次数。开放区间为首次开放时刻起的连续7×24小时，到期即时停止正常学习和复习；首次开放取“分配时刻”和“阶段设定开放时刻”的较晚者。读文件、提问、提交等服务端接口同样检查期限。

超过7天可在亡羊补牢学习提交申请，每次提交计1次，待审核重复点击不重复计数；教师批准后该申请对应阶段开放7天，拒绝也占用一次。按同一邮箱统计整门课最多3次申请，第4次申请锁定该邮箱整门课程的学习入口（包括其他学习安排）。教师可重置次数与锁定状态，原始申请和学习记录保留。

六维只累计期限内的知新学习完成记录。复习和补学均单独记录，不增加六维百分比；教师可分别看到知新、复习、补学的使用次数。口头题、文档、音频、练习等另列模块完成数。

在线资料没有下载按钮，文档以正文/PDF内嵌方式呈现，播放器隐藏下载菜单。无法从技术上绝对阻止浏览器保存、抓取或录屏；不宣称实现DRM。

运行检查：npm test。新流程覆盖阶段锁定、答案保护、记录去重、收件人隔离、发送幂等和接口权限。浏览器验收使用虚构内容与本机预览，不发实际邮件。验证历史见 docs/验证记录.md。

## 两端语音输入

教师端章节名称、学习要求、题干/选项/解析等文字框，以及学生端AI提问、初步想法、思考题作答框，右侧均有麦克风按钮。点击麦克风→开始录音→结束并识别→检查或修改识别文字→填入文字。每次最长60秒，可手动提前结束。输入在原光标/选区位置填入，原有其余文字保留，超过字段字数限制时提示修改，不自动截断。邮箱、时间等专用字段不添加语音按钮。

使用现有硅基流动语音转写配置，语音传给模型服务；本机不保存语音输入的录音或另建对话/作业记录。填入后仍需自行保存、提问或提交。课堂实录/口头作答录音仍使用原有独立功能。学生语音接口同样验证专属链接、当前阶段与7天/补学权限。识别失败可重试，取消后不填入文字。

麦克风需浏览器授权；本机地址可直接使用，公网使用需HTTPS。已验证桌面Edge的浏览器录音、移动宽度布局及合成中文语音真实转写，未使用用户的真实麦克风。

## 跟随页面的语音导航

两端右下角固定显示“语音导航”，滚动、切换页面后仍保留。点击开始录音后说“打开章节”“去课前任务”“查看学情反馈”“打开温故学习”“打开补学”等，识别到明确目标即跳转。教师也可说完整章节或已保存任务的名称；重名或不明确时提示补充名称。学生过期后仍能语音进入补学申请页，资料本身仍受原权限限制。导航只打开页面，不执行发邮件、删除、提交、审批等动作。麦克风只在点击开始录音后开启。
